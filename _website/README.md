# PavitraBhakti - E-Commerce Divine Pooja Samagri Store

A Next.js 14 e-commerce web application for sacred spiritual products.

## 🚀 Live Demo
Deploys automatically on Vercel from `_website` directory.

## 🛠️ Tech Stack
- Next.js 14 (App Router)
- React 18 & TypeScript
- Tailwind CSS & Lucide Icons
